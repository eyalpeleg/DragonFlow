Task management that keeps you in flow

DragonFlow is a personal task manager built around a simple lifecycle — Ready, In Progress, Paused, Done. Priorities, categories, sub-tasks, recurrence and a Pomodoro timer, with everything stored on your own device.

What's inside

Everything a personal task list actually needs

No boards to configure, no workspaces to invite people to. Just the pieces that help you finish what you started.

Four priority levels

Critical, High, Medium and Low, each with its own colour so the urgent work reads at a glance without opening anything.

Colour-coded categories

Five built-in categories plus as many of your own as you want, each with a colour from the palette. Filter the list down to one in a tap.

Sub-task checklists

Break a task into steps and tick them off inside the task itself. Progress shows on the card, so a big task stops feeling like one item.

Recurring tasks

Daily, weekly or monthly with a custom interval. Completing one occurrence generates the next automatically — no re-typing the same chore.

Pomodoro timer

A focus timer wired to the task you're working on, with its own alarm sounds and a mini-bar that stays visible while you move around the app.

Reminders that arrive

Per-task due-date reminders, a daily summary of what's on today, and a nudge for anything Critical — on their own notification channels.

Daily & weekly progress

Completion counts, a category breakdown and a week-at-a-glance view, so finishing things leaves a trail you can actually look back at.

Light and dark

A full dark palette across every screen, switched from Settings — not a dimmed overlay bolted onto a light theme.

Backup and restore

Export everything to a JSON file you keep, or sign in to back up to a private Google Drive folder — automatically, in the background.

Android overlay

The tasks that matter stay on screen

DragonFlow draws a small draggable bubble on top of whatever you're doing, showing how many urgent tasks are waiting. Move it anywhere, drag it to the dismiss zone to hide it, tap it to jump straight back into the app.

  • Counts in-progress and urgent work, scored by priority and due date
  • Survives a reboot — it comes back on its own
  • Entirely optional, and switched off from Settings whenever you like

Local-first by design

Your tasks stay on your phone

There is no DragonFlow server. No account to create, no analytics, no ad network — the app works completely offline.

Stored on device

Tasks, categories and settings live in the app's private storage. Nothing is uploaded unless you turn on backup yourself.

Backup you control

Google Drive backup is opt-in and writes to appDataFolder — a private space only DragonFlow can read. It never touches the rest of your Drive.

Nothing phones home

No telemetry, no crash reporting, no third-party SDKs collecting behaviour. The source is public if you'd rather check than take our word for it.

Getting started

Install on your Android device

DragonFlow isn't on the Play Store yet, so it installs from a signed APK.

  1. Download the APK Grab the latest release from GitHub Releases on the phone itself, or copy it across from your computer.
  2. Allow the install Android will ask permission to install from your browser or file manager the first time. Approve it under Settings → Apps → Special access → Install unknown apps.
  3. Open it and start adding tasks No sign-up, no onboarding wall. The app is usable the moment it launches.
  4. Optional: turn on the extras Grant notifications for reminders, the "display over other apps" permission for the floating bubble, and sign in to Google Drive if you want automatic backups.

Prefer to build it yourself? Clone the repo, run npm install and npm run android. The full setup — including the Android toolchain — is documented in the README.
